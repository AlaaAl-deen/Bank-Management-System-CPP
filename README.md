# 🏦 Bank Management System in C++

A console-based Bank Management System developed in C++ as part of my programming journey in **Course Seven**.

The project focuses on managing client records, performing banking transactions, and storing data in files, while applying clean code principles to improve readability and maintainability.

## 📌 Overview

The Bank Management System provides a menu-driven interface that allows users to manage clients and perform basic banking operations through a console application.

It was developed as a practical learning project to strengthen my understanding of C++ programming, file handling, and software development fundamentals.

## ✨ Features

### 👥 Client Management
- Display the list of clients.
- Add new clients.
- Delete existing clients.
- Update client information.
- Search for clients.

### 💰 Banking Transactions
- Deposit money.
- Withdraw money.
- Display total balances.
- Navigate between the main menu and the transactions menu.

### 📁 File Handling
- Store client data in text files.
- Preserve data between program executions.
- Practice file input and output in C++.

### 🧹 Code Quality
- Apply clean code principles.
- Organize code into readable and maintainable components.
- Use meaningful names and clear program flow.

## 🛠️ Technologies Used

- **Language:** C++
- **IDE:** Microsoft Visual Studio
- **Application Type:** Console Application
- **Data Storage:** Text files

## 🚀 Getting Started

### Prerequisites
- Microsoft Visual Studio with C++ development tools installed.
- A Windows environment compatible with the project configuration.

### Run the Project
1. Clone or download this repository.
2. Open `BankProject.sln` in Visual Studio.
3. Select the appropriate build configuration.
4. Build the solution.
5. Run the application and follow the on-screen menu.
